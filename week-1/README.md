# Launchpad — YuvaIntern Week 1

A static learning hub built with semantic HTML and CSS for **Week 1: Transforming Wireframes into Static Web Pages**.

## View the page
Download the repository and open `index.html` in a browser. No installation or build step is required. Keep `styles.css` and `wireframe.svg` alongside the HTML file.

## Files
- `index.html` — complete static webpage
- `styles.css` — page styling and basic media queries
- `wireframe.svg` — original desktop and mobile layout concept
- `REPORT.md` — brief technical report
- `Week-1-Report.docx` — Word report for the YuvaIntern upload form
- `description.txt` — submission description of more than 200 words
- `TESTING.md` — checks and limitations

## Layout and decisions
The page follows an original wireframe: header, split hero, principles strip, three learning cards, process, about, and footer. The wireframe was created for this assignment; it is not an official YuvaIntern reference. Grid defines the primary layout and Flexbox aligns smaller groups. A neutral background, purple accent, system fonts, and a CSS illustration avoid external dependencies. Navigation uses real section anchors. Learning track content is illustrative, with no course enrollment service.

## Scope
Only Week 1 is implemented. Basic responsiveness is part of that week's stated requirements. There is no JavaScript, backend, login, or implementation of Weeks 2–5.
