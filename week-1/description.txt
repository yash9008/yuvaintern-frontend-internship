This Week 1 submission presents Launchpad, a static learning hub webpage created for the YuvaIntern Frontend Web Developer internship. The project demonstrates how an original wireframe can be translated into a complete webpage using HTML and CSS. The wireframe defines the main navigation, a two-column hero area, a learning principles strip, three learning track cards, a process section, an about section, and a footer.

The HTML uses semantic elements, including header, nav, main, section, article, and footer, to organize the content into a clear hierarchy. A separate CSS file controls typography, colors, spacing, borders, and layout. CSS Grid is used for the larger page sections and card arrangement, while Flexbox aligns navigation links, labels, and smaller content groups. A warm neutral background, purple accents, and consistent spacing establish a simple visual identity. The hero illustration is constructed with HTML and CSS, avoiding external image dependencies.

Basic media queries adapt the original layout to smaller screens, as required by the Week 1 task. The hero, cards, and process steps stack vertically on phones, while navigation remains visible and wraps when needed. Internal links connect the navigation and call-to-action elements to meaningful page sections. A skip link and visible keyboard focus styling support navigation.

The accompanying report explains the wireframe, design decisions, implementation approach, layout challenges, and validation results. The project includes the HTML file, stylesheet, original wireframe, and documentation. Its scope is limited to Week 1 and does not include JavaScript features, account systems, or later internship tasks.
